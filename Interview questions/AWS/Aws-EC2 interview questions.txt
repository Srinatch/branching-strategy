AWS EC2 Interview Questions and Answers (Complete Guide)
-------------------------------------------------------
1. What is EC2?
-------------------------------------------------------
Amazon Web Services EC2 (Elastic Compute Cloud) is a web service that provides scalable virtual servers (instances) in the cloud.
Features
Resizable compute capacity
Pay-as-you-go pricing
Multiple instance types
High availability
Auto Scaling support

2. What are the Main Components of EC2?
-------------------------------------------------------
AMI (Amazon Machine Image)
Instance Types
EBS Volumes
Security Groups
Key Pairs
Elastic IP
Network Interfaces

3. What is an AMI?
-------------------------------------------------------
An AMI (Amazon Machine Image) is a template used to launch EC2 instances.

It contains:
Operating System
Application Server
Configuration settings

Examples:
Amazon Linux
Ubuntu
Red Hat
Windows

4. What is an EC2 Instance?
-------------------------------------------------------
An EC2 instance is a virtual machine running in AWS.

5. Types of EC2 Instances
-------------------------------------------------------
Family		Purpose
T Series	General purpose
M Series	Balanced workloads
C Series	Compute optimized
R Series	Memory optimized
P Series	GPU workloads
I Series	Storage optimized

6. Explain T2 and T3 Instances
-------------------------------------------------------
Burstable performance instances suitable for:

Web servers
Small databases
Development environments

Example:
t2.micro
t3.micro

-------------------------------------------------------
T2						T3

-------------------------------------------------------

-------------------------------------------------------

11. What is EBS?
-------------------------------------------------------
Amazon Web Services EBS (Elastic Block Store) provides persistent block storage for EC2 instances.

12. Types of EBS Volumes
-------------------------------------------------------
Volume 	Type					Usage
gp3		General purpose 		SSD
io2		High-performance 		SSD
st1		Throughput optimized 	HDD
sc1		Cold 					HDD

13. Difference Between EBS and Instance Store
-------------------------------------------------------
EBS						Instance Store
Persistent				Temporary
Network attached		Physically attached
Snapshot support		No snapshot

14. What is an EBS Snapshot?
-------------------------------------------------------
A backup of an EBS volume stored in S3.

15. Can You Attach One EBS Volume to Multiple Instances?
--------------------------------------------------------
Multi-Attach is supported only with io1/io2 volumes and specific instance types.

16. What is an Elastic IP?
-------------------------------------------------------
A static public IPv4 address assigned to EC2 instances.

17. Why Use Elastic IP?
-------------------------------------------------------
Static IP
Disaster recovery
Easy remapping

18. What is ENI?
-------------------------------------------------------

MAC address
