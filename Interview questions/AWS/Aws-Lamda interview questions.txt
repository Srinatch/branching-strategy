AWS Lambda – Complete Interview Questions and Answers
-----------------------------------------------------
1. What is AWS Lambda?
-----------------------------------------------------
Amazon Web Services Lambda is a serverless compute service that runs code without provisioning or managing servers. 
You upload your code, and Lambda automatically scales and executes it in response to events.
Benefits
Serverless
Automatic scaling
Pay only for usage
High availability
Supports multiple languages

2. What is Serverless Computing?
-----------------------------------------------------
Serverless computing allows developers to run applications without managing infrastructure.

AWS manages:
Servers
Scaling
Availability
Patching

3. Which Languages Does Lambda Support?
-----------------------------------------------------
Python
Node.js
Java
C#
Go
Ruby
Custom Runtime

4. What Are the Components of Lambda?
-----------------------------------------------------
Function
Event Source
Trigger
Execution Role
Environment Variables
Layers

5. What is a Lambda Function?
-----------------------------------------------------
A Lambda function is a piece of code executed in response to events.

Example:
def lambda_handler(event, context):
    return "Hello AWS"
	
6. What Are Lambda Triggers?
-----------------------------------------------------
Services that invoke Lambda automatically.

Examples:
S3
API Gateway
DynamoDB
EventBridge
SNS
SQS
CloudWatch

7. Explain Event-Driven Architecture
-----------------------------------------------------
S3 Upload
    ↓
Lambda
    ↓
Process File
    ↓
Store Results

Lambda executes when an event occurs.

8. What is the Lambda Handler?
-----------------------------------------------------
The handler is the entry point for a Lambda function.

Python:
def lambda_handler(event, context):
    pass
	
9. What are Event and Context Objects?
-----------------------------------------------------
Event
Contains input data.

Context
Provides runtime information.

Examples:
Request ID
Remaining execution time
Function name

10. What is Stateless Execution?
-----------------------------------------------------
Lambda does not retain state between invocations.

State should be stored externally:
DynamoDB
S3
RDS

11. How Does Lambda Scale?
-----------------------------------------------------
Lambda automatically creates multiple instances to handle concurrent requests.

12. What is Concurrency?
-----------------------------------------------------
Number of simultaneous Lambda executions.

13. Reserved Concurrency vs Provisioned Concurrency
-----------------------------------------------------
Reserved Concurrency			Provisioned Concurrency
Limits executions				Eliminates cold starts
Controls capacity				Keeps environments warm

14. What is a Cold Start?
-----------------------------------------------------
Time required to initialize a new Lambda execution environment.

Factors:
Runtime
Package size
VPC configuration

15. How Can Cold Starts Be Reduced?
-----------------------------------------------------
Provisioned concurrency
Smaller deployment packages
Lightweight runtimes

16. Deployment Package Types
-----------------------------------------------------
ZIP Package
Upload code directly.
Container Image
Deploy using Docker images.
Maximum image size:
10 GB

17. Maximum Deployment Package Size
-----------------------------------------------------
ZIP upload: 50 MB

ZIP through S3: 250 MB

18. What are Lambda Layers?
-----------------------------------------------------
Layers contain reusable code and libraries shared among functions.

Benefits:
Code reuse
Smaller packages
Easier maintenance

19. How is Lambda Secured?
-----------------------------------------------------
Using:
IAM roles
Resource policies
Environment variable encryption
VPC

20. Why Use IAM Roles Instead of Access Keys?
-----------------------------------------------------
IAM roles provide:
Temporary credentials
Better security
Automatic rotation

21. Can Lambda Access S3?
-----------------------------------------------------
Yes.
By attaching an IAM role with S3 permissions.

22. What are Environment Variables?
-----------------------------------------------------
Configuration values used by Lambda.

Example:
DB_HOST=mydatabase
DB_PORT=3306

23. Can Environment Variables Be Encrypted?
-----------------------------------------------------
Yes.
Using KMS.

24. Can Lambda Run Inside a VPC?
-----------------------------------------------------

Used to access:
RDS

Internal applications

25. Drawback of VPC Lambda?
-----------------------------------------------------
