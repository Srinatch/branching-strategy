Docker Full Interview Questions & Answers
-------------------------------------------------
What is Docker?
-------------------
Docker is an open-source containerization platform that allows developers to package applications 
and their dependencies into lightweight, portable containers.

Benefits
--------------
Portability
Faster deployment
Consistent environments
Resource efficiency
Scalability

1. What is Containerization?
------------------------------
Containerization is a method of packaging an application along with its dependencies so it can run consistently across different environments.

2. What is a Container?
--------------------------
A container is a lightweight, standalone executable package that contains:

Application code
Runtime
Libraries
Dependencies

3. What is the Difference Between a Container and a Virtual Machine?
--------------------------------------------------------------------
Container	                     Virtual Machine
Shares host OS kernel	         Has its own OS
Lightweight	                     Heavyweight
Fast startup	                 Slow startup
Less resource usage	             More resource usage

Architecture
-------------------
Docker Container
----------------
App
Libraries
Docker Engine
Host OS
Virtual Machine
---------------
App
Libraries
Guest OS
Hypervisor
Host OS

4. What is Docker Engine?
-----------------------------
Docker Engine is the core component that runs and manages containers.

Components
----------
Docker Daemon (dockerd)
Docker CLI
REST API

5. What is Docker Daemon?
----------------------------
The Docker daemon is a background service responsible for:
Building images
Running containers
Managing networks
Managing volumes

6. What is Docker Hub?
---------------------------
Docker Hub is a cloud repository used to store and share Docker images.

7. Explain Docker Architecture
-------------------------------
Client
   |
Docker CLI
   |
Docker Daemon
   |
Images | Containers | Networks | Volumes

8. What Happens When You Run a Docker Container?
--------------------------------------------------
Example:
docker run nginx

Steps:
Checks local image
Pulls image if unavailable
Creates container
Starts container
Attaches process

9. What is a Docker Image?
----------------------------
A Docker image is a read-only template used to create containers.

10. What is the Difference Between Image and Container?
---------------------------------------------------------
Image	           Container
Blueprint	      Running instance
Read-only	      Read-write
Static	          Dynamic

11. How to Pull an Image?
-----------------------------
docker pull nginx

12. List Images
------------------
docker images

13. Remove Image
---------------------
docker rmi image_name

14. What is Image Layering?
-------------------------------
Docker images are built in layers.

Example:
Ubuntu Layer
Python Layer
Application Layer

Benefits:
Reusability
Faster builds
Smaller storage

15. What is a Base Image?
-----------------------------
A starting image used for creating custom images.

Examples:
Ubuntu
Alpine Linux
CentOS

26. What is Dockerfile?
----------------------------
A Dockerfile is a text file containing instructions for building Docker images.

27. Common Dockerfile Instructions
------------------------------------
Instruction	 Purpose
FROM		 Base image
RUN	    	 Execute command
COPY		 Copy files
ADD	    	 Add files
WORKDIR		 Set working directory
CMD	     	 Default command
ENTRYPOINT	 Main executable
ENV	     	 Environment variable

28. Example Dockerfile
-------------------------
FROM ubuntu
WORKDIR /app
COPY . .
RUN apt-get update
CMD ["echo","Hello Docker"]

29. Build Docker Image
----------------------------
docker build -t myapp .

30. Difference Between COPY and ADD
--------------------------------------
COPY	           ADD
Copies files	   Copy + URL support
Preferred	       Additional features

31. Difference Between CMD and ENTRYPOINT
-----------------------------------------
CMD	                ENTRYPOINT
Default command	    Fixed executable
Can be overridden	Harder to override

Example:
CMD ["python","app.py"]
ENTRYPOINT ["python"]

32. What is Docker Networking?
--------------------------------
Allows communication between:
Containers
Host machine
External systems

33. Types of Docker Networks
--------------------------------
Bridge:
Default network.
Host:
Uses host networking.
None:
No networking.
Overlay:
Multi-host networking.
Macvlan:
Assigns MAC address.

34. Create Network
------------------------------
docker network create mynetwork

35. List Networks
----------------------------------
docker network ls

36. Inspect Network
----------------------------------
docker network inspect mynetwork

37. Connect Container to Network
----------------------------------
docker network connect mynetwork container_name

38. What is a Docker Volume?
----------------------------------
Volumes provide persistent storage for containers.

39. Why Use Volumes?
----------------------------------
Containers are temporary.

Volumes preserve:
Database files
Logs
Uploads

40. Create Volume
----------------------------------
docker volume create myvolume

41. List Volumes
----------------------------------
docker volume ls

42. Mount Volume
----------------------------------
docker run -v myvolume:/app/data nginx

43. Difference Between Volume and Bind Mount
--------------------------------------------
Volume	             Bind Mount
Managed by Docker	 Managed by Host
Portable	         Host dependent

44. What is Docker Compose?
----------------------------------
Docker Compose manages multi-container applications using YAML files.

45. Why Use Docker Compose?
----------------------------------
Multiple services
Single command deployment
Easy networking

46. Example docker-compose.yml
----------------------------------
version: '3'
services:
  web:
    image: nginx

  db:
    image: mysql
	
47. Start Compose Services
----------------------------------
docker-compose up
Detached:
docker-compose up -d

48. Stop Compose Services
----------------------------------
docker-compose down

----------------------------------

54. What are Docker Secrets?

55. What is Docker Swarm?
----------------------------------

----------------------------------

----------------------------------

58. Scale Service
----------------------------------

59. What is Multi-stage Build?
----------------------------------
Reduces image size by separating build and runtime stages.

Example:

FROM openjdk

60. What is Docker Cache?
----------------------------------

------------------------------------

Remove unnecessary files
Minimize layers
