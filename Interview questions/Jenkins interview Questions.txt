1. What is Continuous Integration (CI)?

Continuous Integration is the practice of automatically integrating code changes 
from multiple developers into a shared repository several times a day.
Benefits
Early bug detection
Faster development
Automated testing
Better code quality

2. What is Continuous Delivery (CD)?

Continuous Delivery ensures code is always ready for deployment through automated pipelines.

3. What is Continuous Deployment?

Continuous Deployment automatically deploys every successful change to production without manual approval.

6. What is Jenkins Pipeline?

A Jenkins Pipeline is a suite of plugins that supports implementing CI/CD pipelines as code.

7. Types of Jenkins Pipelines

Type	                    Description
Declarative Pipeline	    Simpler syntax
Scripted Pipeline	        Groovy-based advanced scripting

8. What is Jenkinsfile?

A Jenkinsfile defines the Jenkins pipeline in code form.

Example:

pipeline {
    agent any

    stages {
        stage('Build') {
            steps {
                echo 'Building Application'
            }
        }
    }
}

9. Explain Declarative Pipeline

Simplified syntax introduced for readability and easier maintenance.

Example
pipeline {
    agent any

    stages {
        stage('Test') {
            steps {
                echo 'Running Tests'
            }
        }
    }
}

10. Explain Scripted Pipeline

Uses Groovy scripting for complex logic.
Example:

node {
    stage('Build') {
        echo 'Building'
    }
}

62. How Do You Schedule Jenkins Jobs?

Using CRON syntax.
Example:
H/15 * * * *
Runs every 15 minutes.
Jenkinsfile Full Example
pipeline {
    agent any

    environment {
        APP_ENV = 'dev'
    }

    stages {

        stage('Checkout') {
            steps {
                git 'https://github.com/user/repo.git'
            }
        }

        stage('Build') {
            steps {
                sh 'mvn clean install'
            }
        }

        stage('Test') {
            steps {
                sh 'mvn test'
            }
        }

        stage('Deploy') {
            steps {
                echo 'Deploying Application'
            }
        }
    }

    post {
        success {
            echo 'Pipeline Successful'
        }

        failure {
            echo 'Pipeline Failed'
        }
    }
}
