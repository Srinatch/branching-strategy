Kubernetes Full Interview Questions & Answers
-------------------------------------------------------
What is Kubernetes?
-------------------------------------
Kubernetes (K8s) is an open-source container orchestration platform used to automate:
Container deployment
Scaling
Load balancing
Self-healing
Service discovery

Originally developed by Google and now maintained by the Cloud Native Computing Foundation.

1. What is Container Orchestration?
-------------------------------------
Container orchestration automates:
Deployment
Scaling
Networking
Monitoring
Management of containers

2. Why Kubernetes?
-------------------------------------
Benefits
Auto-scaling
Self-healing
Load balancing
Rolling updates
Service discovery
High availability

3. What Problems Does Kubernetes Solve?
---------------------------------------
Managing thousands of containers
High availability
Resource optimization
Application scaling
Automated deployments

4. What is a Kubernetes Cluster?
-------------------------------------
A Kubernetes cluster consists of:
Control Plane (Master)
        ↓
Worker Nodes
        ↓
Pods

5. Explain Kubernetes Architecture
-------------------------------------
Control Plane Components
API Server
Scheduler
Controller Manager
etcd
Worker Node Components
Kubelet
Kube Proxy
Container Runtime

6. What is API Server?
-------------------------------------
The API Server is the central management component of Kubernetes.
Functions:
Accepts API requests
Validates requests
Updates cluster state

7. What is etcd?
-------------------------------------
etcd is a distributed key-value database used to store cluster configuration and state.

8. What is Scheduler?
-------------------------------------
The Scheduler decides which node should run a pod.
Factors:
CPU
Memory
Affinity rules
Resource availability

9. What is Controller Manager?
-------------------------------------
Maintains desired cluster state.
Examples:
Deployment Controller
Node Controller
ReplicaSet Controller

10. What is Kubelet?
-------------------------------------
Kubelet is an agent running on each node.
Responsibilities:
Pod management
Container health monitoring
Communication with API Server

11. What is Kube Proxy?
-------------------------------------
Handles networking and service routing between pods.

12. What is a Pod?
-------------------------------------
A Pod is the smallest deployable unit in Kubernetes.
A Pod may contain:
One container
Multiple containers

13. Why Pods Instead of Containers?
-------------------------------------
Pods provide:
Shared networking
Shared storage
Container grouping

14. Create a Pod
-------------------------------------
apiVersion: v1
kind: Pod
metadata:
  name: nginx-pod
spec:
  containers:
  - name: nginx
    image: nginx

Apply:
kubectl apply -f pod.yaml

15. View Pods
-------------------------------------
kubectl get pods

16. Describe Pod
-------------------------------------
kubectl describe pod nginx-pod

17. Delete Pod
-------------------------------------
kubectl delete pod nginx-pod

18. What is ReplicaSet?
-------------------------------------
ReplicaSet ensures a specified number of pod replicas are always running.
Example:
replicas: 3

19. Why Use ReplicaSet?
-------------------------------------
High availability
Fault tolerance
Auto-recovery

20. What is Deployment?
-------------------------------------
A Deployment manages:
ReplicaSets
Rolling updates
Rollbacks

21. Deployment Example
-------------------------------------
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx
spec:
  replicas: 3

  selector:
    matchLabels:
      app: nginx

  template:
    metadata:
      labels:
        app: nginx

    spec:
      containers:
      - name: nginx
        image: nginx

22. Create Deployment
-------------------------------------
kubectl apply -f deployment.yaml

23. Scale Deployment
-------------------------------------
kubectl scale deployment nginx --replicas=5

24. Check Deployments
-------------------------------------
kubectl get deployments

25. Rollout Status
-------------------------------------
kubectl rollout status deployment/nginx

26. Rollback Deployment
-------------------------------------
kubectl rollout undo deployment/nginx

54. What is CronJob?
-------------------------------------

Example:

55. What are Requests and Limits?
-------------------------------------
Request
Guaranteed resources.
Limit
Maximum resources.
Example:
resources:
  requests:
    memory: "256Mi"
    cpu: "250m"

  limits:
    memory: "512Mi"
    cpu: "500m"

56. What Happens If Limits Are Exceeded?
----------------------------------------
CPU throttling
Memory OOMKill

57. What is HPA?
-------------------------------------
Horizontal Pod Autoscaler automatically scales pods.

58. HPA Example
-------------------------------------

--min=2 \

59. What is VPA?
-------------------------------------
Vertical Pod Autoscaler adjusts CPU and memory resources.

79. What is Taint?
-------------------------------------
Restricts pods from scheduling on nodes.
Example:
kubectl taint nodes node1 key=value:NoSchedule

80. What is Toleration?
-------------------------------------
Allows pods to run on tainted nodes.

81. What is Node Affinity?
-------------------------------------
Schedules pods based on node labels.

82. What is Pod Affinity?
-------------------------------------
Schedules pods near other pods.

83. What is Pod Anti-Affinity?
-------------------------------------
Prevents pods from being placed together.
