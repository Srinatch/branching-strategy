Basic Git Questions
-------------------------------
1. What is Git?

Git is a distributed version control system used to track changes in source code and collaborate with others on software projects.

2. What is the difference between Git and GitHub?

Git: A version control tool installed locally on your computer.
GitHub: A cloud-based platform that hosts Git repositories and provides collaboration features.

3. What is a repository (repo)?

A repository is a storage location that contains project files, code, and the complete history of changes.

4. How do you initialize a Git repository?

git init

5. How do you check the status of your repository?

git status

6. How do you add files to the staging area?

git add filename
Or all files:
git add .

7. What is a commit?

A commit is a snapshot of changes saved in Git's history.

8. How do you commit changes?

git commit -m "Your commit message"

9. How do you view commit history?

git log

10. What is the staging area?

The staging area is an intermediate space where changes are prepared before committing.

11. What is a branch?

A branch is an independent line of development that allows you to work on features without affecting the main codebase.

12. How do you create a new branch?

git branch feature-branch

13. How do you switch branches?

git checkout feature-branch
Or:
git switch feature-branch

14. How do you create and switch to a branch in one command?

git checkout -b feature-branch

15. How do you merge a branch?

git merge feature-branch

16. What is a merge conflict?

A merge conflict occurs when Git cannot automatically combine changes from different branches.

17. How do you connect a local repository to GitHub?

git remote add origin https://github.com/user/repo.git

18. How do you push code to GitHub?

git push origin main

19. How do you pull changes from GitHub?

git pull origin main

20. How do you clone a repository?

git clone https://github.com/user/repo.git

21. What is the difference between git fetch and git pull?

git fetch: Downloads changes but doesn't merge them.
git pull: Downloads and merges changes automatically.

22. What does git stash do?

Temporarily saves uncommitted changes without committing them.
git stash

23. How do you view branches?

git branch

All branches:
git branch -a

24. How do you delete a branch?

git branch -d branch-name

25. What is .gitignore?

A file that specifies which files Git should ignore.
Example:
node_modules/
*.log
.env

26. What is a Pull Request (PR)?

A Pull Request is a request to merge changes from one branch into another.

27. What is a Fork?

A fork is a personal copy of someone else's repository on GitHub.

28. What is GitHub Actions?

GitHub Actions is a CI/CD tool used to automate workflows such as testing and deployment.

29. What is the difference between a fork and a clone?

----------------------------------------------------------
       Fork	              |     Clone                |
----------------------------------------------------------
Created on GitHub	      | Created on local machine |
Remote copy	              | Local copy               |
Used for contributing     | Used for development     |
----------------------------------------------------------

30. What are Issues in GitHub?

Issues are used to track bugs, tasks, feature requests, and discussions.

31. What is Git Rebase?

Rebase moves commits from one branch onto another to create a linear history.
git rebase main

32. Difference between Merge and Rebase?

--------------------------------------------------------
       Merge	          |     Rebase                 |
--------------------------------------------------------
Preserves history         | Creates cleaner history    |
Creates merge commit      | No merge commit            |
--------------------------------------------------------

33. What is HEAD in Git?

HEAD is a pointer to the current commit or branch you're working on.

34. What is Cherry-picking?

Applying a specific commit from one branch to another.
git cherry-pick commit-id

35. How do you undo the last commit?

Keep changes:
git reset --soft HEAD~1
Remove changes:
git reset --hard HEAD~1

36. What is the difference between Git Reset and Git Revert?

git reset: Removes commits from history.
git revert: Creates a new commit that undoes previous changes.

37. What is a Detached HEAD state?

Occurs when HEAD points directly to a commit instead of a branch.

38. How do you see remote repositories?

git remote -v

39. How do you rename a branch?

git branch -m new-branch-name

40. What is Continuous Integration (CI)?

A practice where code changes are automatically tested and integrated into the main branch.
